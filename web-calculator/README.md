# Calculadora Web

Interface web para a calculadora, implementada em HTML/CSS/JavaScript.

## Como usar

1. Abra o arquivo `index.html` diretamente no navegador, ou
2. Execute um servidor web local:

```bash
# Python 3
python -m http.server 8000

# Node.js (se tiver http-server instalado)
npx http-server

# Ou qualquer outro servidor web local
```

## Funcionalidades

- Interface web responsiva
- Suporte às mesmas operações da versão Python
- Design moderno e intuitivo

## Arquivos

- `index.html` - Interface web completa da calculadora
