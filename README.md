## Calculadora em Python (CLI e GUI)

### Como executar

- CLI passo-a-passo (padrão):

```bash
python main.py
```

- CLI por expressão (como antes):

```bash
python main.py --expressao
```

- GUI (Tkinter):

```bash
python main.py --gui
```

### Funcionalidades

- Operações: `+`, `-`, `*`, `/`, potência (`**` ou `^`), parênteses
- Função: `sqrt(x)`
- Avaliação segura via AST (sem `eval`)

### Exemplos

```text
> (2+3)^2
25
> sqrt(9) + 1/4
3.25
```
